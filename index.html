01 — Theme System

CSS Variables Power Everything

Switch any of the 4 themes above. Every colour, shadow, and surface updates instantly via data-theme on the root element and CSS custom properties.

Dark

Deep navy background, indigo accents, high contrast text for late-night work.

data-theme="dark"

Light

Warm white surface, slate accents, clean and airy for daytime reading.

data-theme="light"

Ocean

Deep teal tones, cyan highlights — calm, focused, like working underwater.

data-theme="ocean"

Forest

Rich greens and amber warmth. Organic, grounded, easy on the eyes.

data-theme="forest"
02 — What's Covered

All Requirements Met

🎨

Theme Switching

CSS custom properties defined per [data-theme] selector. One attribute change on <html> cascades every colour, surface, and shadow instantly.

View components →
📐

Grid & Flexbox

Responsive layouts using CSS Grid for page structure and Flexbox for component internals. Auto-fill columns adapt to any screen width without media query clutter.

See layouts →
⚡

Keyframe Animations

Fade-up, slide-in, pulse, float, and shimmer — all defined with @keyframes and applied via utility classes. Transition delays create staggered entrance effects.

See animations →
♿

Accessibility

Visible focus rings, skip links, ARIA roles, keyboard-navigable components, sufficient colour contrast ratios, and full prefers-reduced-motion support.

A11y details →
🌗

Reduced Motion

The @media (prefers-reduced-motion: reduce) block disables all keyframe animations and transitions for users who have requested less motion in their OS settings.

How it works →
📱

Fully Responsive

Mobile-first breakpoints at 640px, 768px, and 1024px. The navigation collapses to a hamburger menu and all grids reflow gracefully on small screens.

Resize to try →
