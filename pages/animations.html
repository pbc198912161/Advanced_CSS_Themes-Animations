Keyframe Animations

Motion & Transitions

Every animation on this page is defined with pure @keyframes CSS. No JavaScript animation libraries. All animations are disabled automatically when the user's OS has "Reduce motion" turned on.

@keyframes fade-up {
  from { opacity: 0; transform: translateY(30px); }
  to { opacity: 1; transform: translateY(0); }
}
.animate-fade-up {
  animation: fade-up 0.6s var(--ease-out) both;
}

Stagger Effect

Parent gets .animate-stagger · JS adds .is-visible · CSS nth-child delays each item

1 First item — no delay
2 Second item — 80ms delay
3 Third item — 160ms delay
4 Fourth item — 240ms delay
5 Fifth item — 320ms delay
.animate-stagger.is-visible > *:nth-child(1) { transition-delay: 0ms; }
.animate-stagger.is-visible > *:nth-child(2) { transition-delay: 80ms; }
.animate-stagger.is-visible > *:nth-child(3) { transition-delay: 160ms; }
/* ...and so on */

Easing Functions

css/variables.css → --ease-spring, --ease-smooth, --ease-out · hover each bar

--ease-spring cubic-bezier(0.34, 1.56, 0.64, 1) — overshoots then settles

--ease-smooth cubic-bezier(0.4, 0, 0.2, 1) — Material Design standard

--ease-out cubic-bezier(0, 0, 0.2, 1) — fast start, gentle end
