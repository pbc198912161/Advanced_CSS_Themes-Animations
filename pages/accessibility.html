⏭️ Skip Link

css/accessibility.css → .skip-link

A "Skip to main content" link sits at the top of every page. It's invisible until focused — keyboard users press Tab on page load and it appears, letting them jump past the navigation entirely.

Tab on page load to reveal the skip link at the top of this page.
.skip-link {
  position: fixed;
  top: -100%; /* hidden off-screen */
}
.skip-link:focus {
  top: 0; /* jumps into view on focus */
}

🎯 Focus Rings

css/accessibility.css → *:focus-visible

We use :focus-visible — this shows the focus ring only on keyboard navigation, not on mouse clicks. Best of both worlds: mouse users don't see the ring, keyboard users always do.

🎬 prefers-reduced-motion

css/accessibility.css → @media (prefers-reduced-motion: reduce)

Users with vestibular disorders, epilepsy, or motion sensitivity can enable "Reduce motion" in their OS settings. When they do, this media query fires and every animation and transition in the project is disabled instantly — no JS required.

These animations ☝️ are running now.

Enable Reduce Motion in your OS:
macOS → System Settings → Accessibility → Motion
Windows → Settings → Accessibility → Visual Effects

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}

🏷️ ARIA Attributes

Semantic HTML + ARIA where needed

Attribute Where used Why
role="banner" <header> Landmark for screen readers
role="contentinfo" <footer> Footer landmark region
aria-label nav, theme switcher, buttons Describes unlabelled controls
aria-current="page" Active nav link Tells screen reader which page is active
aria-pressed Theme buttons Toggle button state
aria-expanded Mobile menu toggle Open/closed state of menu
aria-controls Menu toggle button Links button to the menu it controls
aria-live="polite" Motion status indicator Announces dynamic changes to screen readers
aria-hidden="true" Decorative icons, orbs Hides decorative elements from screen readers
